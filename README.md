# Genion Web

Website resmi Genion yang dibangun menggunakan React, Vite, Tailwind CSS, dan React Router.

## 🚀 Perintah

Semua perintah dijalankan dari root proyek menggunakan terminal:

| Perintah | Deskripsi |
| :--- | :--- |
| `npm install` | Menginstal dependencies |
| `npm run dev` | Menjalankan server dev lokal |
| `npm run build` | Melakukan build produksi ke `./dist/` |
| `npm run preview` | Meninjau hasil build lokal sebelum deploy |
